# Overbooked!

An Overcooked-style hospital game built with Three.js. Grab supplies, prep treatments and race trays to the right bed before your patients give up.

Play it by opening `index.html` in a browser (an internet connection is needed for Three.js and fonts).

- **Solo:** play as Doctor Tom or Doctor Kate
- **Co-op:** two players on one keyboard or with gamepads
- **Orientation:** a step-by-step tutorial
